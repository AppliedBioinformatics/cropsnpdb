Search the crop single nucleotide polymorphism (SNP) database by querying canola 60k and and wheat 90k arrays.
First select the target species ("Brassica napus" or "Triticum aestivum"). Then select click on the box below "Line" and select one or more lines.
Use the add and remove buttons to move lines between 'Line(s)' and 'Selected Line(s)'.
Only lines in 'Selected Line(s)' will be queried.
Finally, enter a target chromosome (e.g., chrA01_contigs_placed_v81 or 1A_PSMOL_v0.2) and coordinates.
Coordinates and chromosome names are based on the canola Darmor v81 reference and the wheat pangenome respectively.
Query results can be downloaded in tabular csv format with the "Download result" button at the bottom of the page.
Click on each result row to open an information box with additional SNP details.
Example query: “Brassica napus”,"Thunder-TT", "chrA01", "1", "100000".
